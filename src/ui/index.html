    Assumptions and caveats

      Latest scheduled scans

      Cloud Scheduler re-checks the watchlist once a day. Click one to open it.

      Gemini proposes. Code decides.

      The model is never the last word. It has to show its evidence, and plain code checks that evidence before anything counts.

        Model: reads and proposesCode: verifies and decides

        The number that matters is zero.

          Said plainly

          • Most listing texts are written to look like marketplace titles. Five are real titles captured live, including the ones that first slipped through.
          • Labels come from LEGO set numbers. There are no barcode pairs and no image inputs yet.
          • The set is small. Zero false matches here is a floor on the work, not a guarantee.
          • Prices are asking prices. The retail price used to spot bad data is recalled by Gemini, not a live quote.
          • Approving a purchase records a decision. SKUdesk holds no payment details and moves no money.
