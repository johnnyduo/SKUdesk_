SKUdesk

One agent that buys cheapest, helps you sell, and finds arbitrage. Only for the identical product.

If nothing is provably the same item, or no gap survives the costs, it says no. A person approves every spend.

The problem

Price comparison breaks the moment two listings are not the same thing.

We searched Google Shopping for LEGO 10294 Titanic. It returned 36 listings. Among them:

  • Light kits and spare parts that name the set
  • Generic "building blocks" reusing the set number
  • Used and opened boxes
  • Real sets listed at $11 and $19 against a $679.99 retail price

What goes wrong

A naive agent "finds" a 2,000% margin on a $21 Titanic and recommends buying it. The cheapest price is usually the wrong product, or not a real price.

Arbitrage and buying agents are only as good as their idea of "same".

How it works

One gate decides what counts as the same item. Everything else is arithmetic.

1 · SearchGoogle Shopping via SerpApi, eBay API ready. Every paid call cached; monthly cap.
2 · Identity gateGemini compares each listing with the product. It must quote the brand and set number from both listings.
3 · Price sanitySame product, believable price? Far below median or below half of retail is set aside.
4 · EconomicsInteger-cent landed cost, fees, shipping, margin floor. Verdict or an honest no.
5 · ApprovalThe agent files a pending proposal. A person approves. No payment details held.

Buy, sell and arbitrage are three views of the same verified set of identical offers.

Gen AI, done carefully

The model is not trusted. Its evidence is checked.

Running the gate on real listings exposed a failure our hand-made eval missed: the model credited listings with a "LEGO" brand they never wrote, and passed generic blocks that reuse a set number.

Fix: Gemini must copy the brand and identifier out of each listing. Code verifies the quotes are really in the text. Anything it cannot back up becomes "uncertain" and never passes. Errors fail closed.

Defences, all tested

  • Verbatim evidence check on brand and identifier
  • Listing text treated as untrusted (injection pairs in the eval)
  • Price sanity against Gemini's recalled retail price, flagged as recalled, not live
  • "Too good to be true" above a 50% margin

Impact and next

Retail teams lose money on "the same item" that was not.

  • Now: sealed LEGO, US market, five markets selectable
  • Next: GTIN and image evidence, eBay sold-price data, more categories where identity is checkable
  • Principle: the agent's value is knowing when to say no, and showing its evidence when it says yes
